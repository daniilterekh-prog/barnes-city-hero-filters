# BARNES City Hero + Filters

Standalone public package containing the BARNES Moscow city real-estate hero section, quick links, and responsive filter modal.

## Included

- Responsive hero with local background image and logo.
- Search row with filter icon and “Показать объекты”.
- Quick links with expand/collapse behavior.
- Dark filter modal styled from the supplied visual reference.
- Filter parameters copied from the city real-estate reference: property type, price, ranges, area, rooms, districts, finishing, elevator, and trophy property.

## Run locally

Open `index.html` directly or serve the folder with any static file server.
